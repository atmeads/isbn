About data and privacy

Book metadata is fetched from Google Books and Open Library when you look up an ISBN. The book list is stored locally in this browser; it is not synced automatically. Keep your CSV backup if you clear browser data or change phones.

For reliable camera access and installation, host these files on an HTTPS website (for example, GitHub Pages). Opening the HTML directly as a file may disable camera and PWA features.
